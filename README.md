## 🚀 Things I've Built

A few projects from my journey across computer vision, retrieval systems, and real-time AI. Each explores a different problem I'm curious about solving.

### 👁️ [Vision & Spatial Intelligence System](https://github.com/Innovatewithapple/Vision-Assistant)

An end-to-end computer vision project exploring how machines can perceive and reason about physical environments. Combines object detection, instance segmentation, human pose estimation, and 3D spatial understanding, with a focus on camera-based localization and real-world coordinates.

**Build with:** Python · PyTorch · OpenCV · YOLO · MuJoCo

### 🎙️ [VoiceRAG — Real-Time Conversational AI](https://github.com/Innovatewithapple/VoiceRAG-Enhanced-Pipeline)

A real-time voice AI pipeline that brings together streaming speech recognition, retrieval-augmented generation, semantic reranking, LLM inference, and streaming text-to-speech. Designed to support natural conversations with interruption handling and conversational memory.

**Build with:** Python · RAG · Embeddings · Reranking · Qwen · WebSockets · Kokoro TTS

### 🔎 [BERT Dense Retriever](https://github.com/Innovatewithapple/dense-semantic-retrieval)

A dense semantic retrieval project trained on MS MARCO and evaluated across BEIR benchmarks. Focuses on learning meaningful text representations and measuring retrieval quality using metrics such as Recall@K, MRR, and nDCG.

**Build with:** Python · PyTorch · Transformers · MS MARCO · BEIR · FAISS
